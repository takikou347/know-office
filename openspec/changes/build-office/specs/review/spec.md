## ADDED Requirements

### Requirement: know-office の中で確認する

開発中の確認 SHALL GitHub の画面に移らず、know-office のレビューで行える。プルリクエストになる前の作業中の変更も同じ画面で見られる。コードの正本は GitHub のままとし、承認と差し戻し、指摘、直しは MUST GitHub のプルリクエストにも写す。

#### Scenario: 承認を出す

- **WHEN** オーナーがレビューで承認を出す
- **THEN** GitHub のプルリクエストにも可が付く

#### Scenario: 作業中の変更を見る

- **WHEN** 社員がまだプルリクエストを出していないブランチで作業している
- **THEN** オーナーはその変更をレビューで読める

### Requirement: 変更の見せ方

レビュー SHALL 変更したファイルを木で並べ、足した行と消した行を色と記号で分け、行の中で変わった語も示す。変わっていない所は畳む。幅 1,024 ピクセル以上では前と後を左右に並べ、それより狭い時は 1 列にまとめる。

#### Scenario: パソコンで開く

- **WHEN** 幅 1,280 ピクセルの画面で変更を開く
- **THEN** 前と後が左右に並ぶ

#### Scenario: スマートフォンで開く

- **WHEN** 幅 360 ピクセルの画面で変更を開く
- **THEN** 前と後が 1 列にまとまる

### Requirement: 読みやすさと補完

エディタ SHALL 言語ごとの色分け、括弧の対応、折り畳み、定義への移動、型と説明の表示を行い、書く時に言語とフレームワークに合った候補を出す。TypeScript、CSS、Markdown から始め、React、Hono、knowidea-ui のコンポーネントの名前と引数も候補に出す。書き間違いはその場で下線で示す。

#### Scenario: コンポーネントの引数を補完する

- **WHEN** オーナーが knowidea-ui のコンポーネントの名前を書き始める
- **THEN** コンポーネントの名前と引数が候補に出る

#### Scenario: 型の誤り

- **WHEN** オーナーが型の合わない値を書く
- **THEN** その場所に下線が出て、理由が読める

### Requirement: その場で直す

オーナー SHALL レビューで変更を書き換え、同じブランチにコミットできる。

#### Scenario: 直してコミットする

- **WHEN** オーナーが 1 行を書き換えて保存する
- **THEN** 同じブランチにコミットが足され、変更の表示が新しくなる

### Requirement: 指摘

オーナー SHALL 行を選んで指摘を書ける。指摘は作った社員のタスクに戻り、直った後は、前に見た所からの差だけを見られる。

#### Scenario: 指摘がタスクに戻る

- **WHEN** オーナーが行に指摘を書く
- **THEN** 作った社員のタスクにその指摘が足される

#### Scenario: 直った後の差

- **WHEN** 社員が指摘を直して push する
- **THEN** オーナーは前に見た所からの差だけを開ける

### Requirement: 社員の所見と判断

レビュー担当 SHALL 変更の要点と気になる所を先に書く。レビューはチェックの結果とレビュー担当の所見を並べて出し、オーナーが承認か差し戻しを出せるようにする。

#### Scenario: 要点から読む

- **WHEN** オーナーがレビューを開く
- **THEN** レビュー担当の要点とチェックの結果が、変更の前に出る

### Requirement: ワークスペースを起こす時

変更を読むだけの時 MUST ワークスペースを起こさず、ゲートウェイが GitHub から取って見せる。補完と定義への移動を使う時だけワークスペースを起こす。

#### Scenario: 読むだけ

- **WHEN** オーナーが変更を開いて読む
- **THEN** ワークスペースは起きない

#### Scenario: 補完を使う

- **WHEN** オーナーが書き換えを始める
- **THEN** ワークスペースが起き、補完の候補が出る

### Requirement: コンポーネントの置き場

変更を見せるコンポーネントとエディタのコンポーネント SHALL knowidea-ui に足し、know-office はそのバージョンを入れて使う。エディタは CodeMirror 6 で作る。

#### Scenario: コンポーネントを入れる

- **WHEN** know-office がレビューを組む
- **THEN** knowidea-ui の変更を見せるコンポーネントとエディタのコンポーネントを使う

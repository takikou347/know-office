## ADDED Requirements

### Requirement: know-office の中で確認する

開発中の確認 SHALL GitHub の画面に移らず、know-office のレビューの画面で行える。プルリクエストになる前の作業中の変更も同じ画面で見られる。コードの正本は GitHub のままとし、可否、指摘、直しは MUST GitHub のプルリクエストにも写す。

#### Scenario: 可を出す

- **WHEN** オーナーがレビューの画面で可を出す
- **THEN** GitHub のプルリクエストにも可が付く

#### Scenario: 作業中の変更を見る

- **WHEN** 社員がまだプルリクエストを出していないブランチで作業している
- **THEN** オーナーはその変更をレビューの画面で読める

### Requirement: 変更の見せ方

レビューの画面 SHALL 変更したファイルを木で並べ、足した行と消した行を色と記号で分け、行の中で変わった語も示す。変わっていない所は畳む。幅 1,024 ピクセル以上では前と後を左右に並べ、それより狭い時は 1 列にまとめる。

#### Scenario: パソコンで開く

- **WHEN** 幅 1,280 ピクセルの画面で変更を開く
- **THEN** 前と後が左右に並ぶ

#### Scenario: スマートフォンで開く

- **WHEN** 幅 360 ピクセルの画面で変更を開く
- **THEN** 前と後が 1 列にまとまる

### Requirement: 読みやすさと補完

エディタ SHALL 言語ごとの色分け、括弧の対応、折り畳み、定義への移動、型と説明の表示を行い、書く時に言語とフレームワークに合った候補を出す。Rust、TypeScript、CSS、Markdown から始め、Next.js、React、knowidea-ui の部品の名前と引数も候補に出す。書き間違いはその場で下線で示す。

#### Scenario: 部品の引数を補完する

- **WHEN** オーナーが knowidea-ui の部品の名前を書き始める
- **THEN** 部品の名前と引数が候補に出る

#### Scenario: 型の誤り

- **WHEN** オーナーが型の合わない値を書く
- **THEN** その場所に下線が出て、理由が読める

### Requirement: その場で直す

オーナー SHALL レビューの画面で変更を書き換え、同じブランチにコミットできる。

#### Scenario: 直してコミットする

- **WHEN** オーナーが 1 行を書き換えて保存する
- **THEN** 同じブランチにコミットが足され、変更の表示が新しくなる

### Requirement: 指摘

オーナー SHALL 行を選んで指摘を書ける。指摘は作った社員の仕事に戻り、直った後は、前に見た所からの差だけを見られる。

#### Scenario: 指摘が仕事に戻る

- **WHEN** オーナーが行に指摘を書く
- **THEN** 作った社員の仕事にその指摘が足される

#### Scenario: 直った後の差

- **WHEN** 社員が指摘を直して push する
- **THEN** オーナーは前に見た所からの差だけを開ける

### Requirement: 社員の所見と判断

見る役 SHALL 変更の要点と気になる所を先に書く。レビューの画面は検査の結果と見る役の所見を並べて出し、オーナーが可か不可を出せるようにする。

#### Scenario: 要点から読む

- **WHEN** オーナーがレビューを開く
- **THEN** 見る役の要点と検査の結果が、変更の前に出る

### Requirement: 作業場を起こす時

変更を読むだけの時 MUST 作業場を起こさず、入口が GitHub から取って見せる。補完と定義への移動を使う時だけ作業場を起こす。

#### Scenario: 読むだけ

- **WHEN** オーナーが変更を開いて読む
- **THEN** 作業場は起きない

#### Scenario: 補完を使う

- **WHEN** オーナーが書き換えを始める
- **THEN** 作業場が起き、補完の候補が出る

### Requirement: 部品の置き場

変更を見せる部品とエディタの部品 SHALL knowidea-ui に足し、know-office はその版を入れて使う。エディタは CodeMirror 6 で作る。

#### Scenario: 部品を入れる

- **WHEN** know-office がレビューの画面を組む
- **THEN** knowidea-ui の変更を見せる部品とエディタの部品を使う
